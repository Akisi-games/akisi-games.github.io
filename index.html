WEB TOOL / ARBS

ARBS Prefab Analyzer

ARBS のプレハブファイル（WEP_ANIM_PREF_*）をブラウザ内で解析。ベースユニット・HP / 攻撃倍率・スケール・装着武器を一覧表示し、攻撃倍率を編集してそのままダウンロード可能。複数ファイル同時処理＆完全ローカル動作でサーバー送信なし。

Binary ParseMulti-FileEdit & Export100% Local
Launch Tool ⚡
$ load WEP_ANIM_PREF_dragon_07.bin
✔ base_unit  : Dragon
✔ hp_mult    : 2.40
✔ atk_mult   : 3.15 → editable
✔ weapons    : PlasmaCannon ×2
$ export --patched
